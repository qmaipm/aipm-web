## A. 口径（逐条必过）

| # | 检查项 | 通过标准 |
|---|---|---|
| A1 | 四个名称 | 统一写「××智能体群」；每页说明「由多个岗位智能体组成」 |
| A2 | 岗位智能体数量 | 只写「50 多个岗位智能体」，**不出现任何岗位名称** |
| A3 | 服务标准数量 | 只写「几十套服务标准」 |
| A4 | 服务设计三件事 | 服务标准 + 人员编制 + 项目预算；降本从这里开始 |
| A5 | 「少数」口径 | 写「能逐点位算出项目预算的物业公司是少数」，并说明原因是工作量和数据，不暗示能力问题；**不出现「80%」** |
| A6 | 已删除 | 「约 30 分钟出底稿」及一切「30 分钟」说法 |
| A7 | 不出现 | 业委会、自管小区（统一归入「业主」） |
| A8 | 运营管理口径 | IoT 感知替代人盯人；前提是先有服务标准；智能审批、调度派单、现场管理 |
| A9 | 质量评估口径 | 数据源：监控摄像头、手机、机器人、无人机（无人机只写「可接入」，无案例）；能力：保洁质检、拍照抄表、安全隐患识别、设备巡检 |
| A10 | 服务优化口径 | 报告（日 / 周 / 月）、建议（优化 / 调整）、结算（供应商账单、员工薪资、团队 KPI） |
| A11 | 数字白名单 | 只用 §4a 或案例页已发布数字；协同中心测算数字按截图原值（496 个点位、12,496 次/月、室内机器人 4 台另含 3 部梯控改造、9 人＝前线 8＋管理 1、64,906.92 元/月、778,883.00 元/年、59 条明细归并为 20 类），并注明「规模不大、真实项目测算」 |
| A12 | 「3 分钟」 | 百强集团报告的「3 分钟」不作为业务结果强调 |
| A13 | 禁用词 | 留痕、管控、门控、控制层、收口、赋能、抓手、闭环、拉通：四页及联动文件新增 0 处（`npm run -s words:lint` 不新增命中） |
| A14 | 产品模块区 | 四页删除「背后是这些产品模块」；/agents 删除「相关产品」 |
| A15 | 竞品 | 不点名国际顾问公司，写「国际物业顾问」 |
