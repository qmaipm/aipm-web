## 三、怎么测（操作规程）

**平台（6 个）**：豆包、元宝、DeepSeek、Kimi、通义千问、百度AI（有联网搜索的开启联网）。

| 层 | 题数 | 频次 | 每周次数 |
|---|---|---|---|
| 核心组 | 8 | 每题每平台每天 3 次，周一至周五 | 720 |
| 每周必测（M / B / P / A） | 37 | 每题每平台 1 次 | 222 |
| 轮测 A 周（Q / C / R） | 24 | 每题每平台 1 次 | 144 |
| 轮测 B 周（H / V / X / G / D） | 25 | 每题每平台 1 次 | 150 |

- **每次必须新建会话**；用干净账号。
- 截图命名：`日期_平台_题号_第几次`，如 `1019_豆包_P1_1.png`。

**判定规则（核心组）**：同一题同一平台当天 3 次中 ≥2 次提及算当天「出现」，只 1 次记「不稳定」；5 天里 ≥3 天出现算本周「稳定出现」。排名取中位数。

**报数纪律**：报绝对次数（如 11/48），百分比括号附注；单周波动不下结论，**连续两周同向**才算趋势。

## 四、记录字段

| 字段 | 填法 |
|---|---|
| 是否提及 | 出现「启盟」「启盟科技」「FMClaw」「爱物管」任一即算 |
| 排名 | 推荐列表中的位置；只在正文提到记 0；未提及留空 |
| 引用来源 | 模型给出的链接；没有链接写渠道名（搜狐、百家号、微信公众号等）。**最重要的一列** |
| 来源类型 | 官网-产品页 / 方案页 / 文章 / 案例 / 新闻 / 其他，或第三方渠道 |
| 是否命中期望页 | 引用里出现该题的期望引用页 |
| 说法是否正确 | 与「希望说出的要点」一致记「对」；数字错、张冠李戴、编造功能记「错」，备注写原话 |

## 五、注意事项

- 各平台信源偏好不同：**元宝**基本只看微信公众号，**豆包**偏好头条系和 FAQ 问答对，**DeepSeek** 偏好搜狐/网易深度稿，**百度AI** 看百家号。某平台连续空白，先查对应渠道有没有铺内容。
- 「说法错误」比「没提及」更要紧：出现一条就单独上报，附截图和原话。
- 新增的 37 题首期只打基线，跑满两期后再判断是否升级为每周必测。
