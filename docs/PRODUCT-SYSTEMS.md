## 一、核心判断：AI 物业管理系统 vs 智慧物业系统

调研后可以用一句话概括客户对传统系统的不满：**系统上了，活还是人在干。**

| | 智慧物业系统（传统） | AI 物业管理系统（我们） |
|---|---|---|
| 入口 | 业主下载 App / 小程序，点来点去、填表 | 业主在小程序或业主群里**说一句话、发一段语音** |
| 建单 | 客服看消息、判断、手工录单 | **自动识别诉求、自动生成工单**，人确认即派 |
| 跟进 | 靠人催、靠人记 | **自动跟进**，超时自动升级到对应层级负责人 |
| 设备 / 车场 / 门禁 | 系统里有数据，要人自己去看 | **AI 主动告诉你**：哪个门禁点坏了、哪里漏水、昨天停车场收了多少、有没有违规抬杆 |
| 报表 | 人去导数、做表、写日报 | **日报自动写好，每天主动发给项目经理** |
| 系统之间 | 收费、工单、门禁、停车各买各的，数据不通 | 一套数据底座，**解决完报修直接弹出收费单**，访客车自动放行计费 |

这张表就是 FAQ“和智慧物业有什么区别”的答案，也是工具箱总页的主线。

## 二、系统地图

格式：**客户痛点（站外调研） → 传统都有的 → 加了 AI 多出来的 → 和谁联动**。
外部数据只用于内部判断；如需上页面，必须注明出处，并先加入白名单（SEO-GEO-STRATEGY §4a）。

### 1. 业主端：业主小程序 / App + 业主 Agent

**重新定义**：以前业主要打开 App 点来点去，或找客服说来说去；现在业主小程序 / App 本身就是一个 **Agent**。它也能在业主群里干活：语音报修、报单，查账单、查进度，叫它办事。它能**查数据、调工具**，一个入口解决业主的所有事。

**客户的核心诉求**：提升客户满意度。在客户眼里，满意就是**更快、更方便、更懂我**。

**痛点（调研）**：

| 痛点 | 依据 |
|---|---|
| 满意度在下滑，已经成为续约的硬门槛 | 克而瑞物管：2025 年全国住宅物业服务满意度 69.1 分，较上年降约 2 分，创近年新低；上海规定满意率低于 80% 的物业不得续聘（2026-02） |
| 投诉响应慢、沟通不顺 | 政府物业服务质量研究把“对业主需求快速准确解答、沟通渠道顺畅、及时有效处理投诉”列为满意度的“响应性”核心指标；北京 2026 年公众满意度调查第一问就是“物业服务响应及时吗” |
| 业主不爱用 App | 2026 年中小物业数字化调研：超过 62% 的物业公司遇到过“物业 App 没人用”，原因是下载门槛高、菜单深、报修要填一堆信息、老人不会用；缴费、报修、门禁各是一个入口 |
| 入口散、重复单 | 物业客服选型文章：业主触点分散在公众号、App、小程序、管家企微，信息不通，在公众号报一次、打电话又报一次，客服看到两条，重复派单 |
| 群消息管不过来 | 一线反馈：一个客服管很多群，回复不及时，投诉看漏，人脑跟不上，还有情绪问题 |
| 建单、跟进全靠人 | 工单系统行业文章的共同说法：报障入口分散、记录难追踪；工单靠人工派发，超时无人管；缺少数据，效率与质量难考核 |
| 处理成本高，客户还不一定满意 | 一线反馈：内部还要花大量成本处理客服带回的信息 |

**传统都有的**：缴费、报事报修、投诉建议、通知公告、访客邀请、开门等。

**加了 AI 多出来的**：
1. **一句话办事**：文字、语音、图片都可以，在小程序里或业主群里都行，不用找入口、不用填表。
2. **工单自动化**：自动收集诉求，自动识别是谁、哪套房、什么问题、急不急、情绪如何，自动生成工单，确认后即派。
3. **自动跟进到办完**：自动催办；没按时办完的，自动升级到相应层级负责人；办完自动回访。
4. **数据看板**：工单看板、工单分析、客户满意度，高频问题和慢环节一眼看出来。

**和谁联动**：收费（办完有偿维修直接弹出收费单）、门禁（访客邀请）、停车（月卡、缴费）。

### 2. 收费系统

**痛点（调研）**：

| 痛点 | 依据 |
|---|---|
| 收缴率连年下滑 | 克而瑞物管：2025 年 500 强平均收缴率 71%，连续四年下滑，中小物企普遍低于 65%；中指研究院：百强平均 87.32%，持续下降 |
| 业主嫌不透明 | 克而瑞：超过 30% 业主认为物业费偏高，核心诉求是收费透明、与服务匹配 |
| 多项目看不清 | 行业文章：多项目集团对单个项目的应收台账、欠费结构、回款节奏看不清；收费系统的欠费台账和财务系统的应收账款往往是两套数，坏账风险发现得晚 |
| 计费复杂、对账费人 | 收费系统厂商普遍提到：收费项目多、公摊和违约金难算、账单错误多、人工对账耗时 |
| 人力成本刚性 | 行业文章：百强物企广义人工成本占总支出约 70%（二手引用，用前需核原始出处） |

**传统都有的**：物业费、水电费、停车费、租金收费，账单、催缴、对账、报表。

**加了 AI 多出来的**：
- **业务直接出账**：客服解决完问题，业主 Agent 给出建议并直接弹出对应收费单；水电表读数直接出账。
- **欠费与应收应付自动分析**：哪个项目、哪类费用、哪些户在变差，自动分层提醒。
- **多项目不用堆财务人员**：项目一多，传统模式要靠大量财务人员做数据处理，现在由 AI 处理。

**和谁联动**：业主端、工单、停车、楼宇自控（表计）。

### 3. 停车系统

**痛点（调研）**：

| 痛点 | 依据 |
|---|---|
| 车辆管理是业主最不满的一项 | 克而瑞：超过 40% 业主对“车辆管理”不满，排第一，集中在乱停放、监控覆盖不全、高峰通行慢 |
| 收入流失、逃费 | 媒体多次报道使用“抬杆神器”逃费、利用系统漏洞两个月逃费 71 次；厂商把“跑冒滴漏导致对账漏洞频发”列为首要痛点；百度高频问题：“停车场逃费如何追回” |
| 日报、分析靠手写 | 百度联想：停车场日报表模板、收费日报表、运营分析报告怎么写 |
| 数据有，没人看 | 停车系统有收费、进出数据，但要项目经理自己登录去看 |

**传统都有的**：车牌识别、道闸、临停计费、月卡、访客车、线上缴费、报表。

**加了 AI 多出来的**：**每天主动把停车日报发给项目经理**，内容包括：
- 收费情况
- 车辆进出流量
- 在场车辆统计
- 长时间停放车辆提醒
- 违规抬杆监控（直接对应逃费、漏收）

**和谁联动**：业主端（月卡、缴费）、门禁访客（访客车）、工单（道闸故障）、收费。

### 4. 门禁与访客系统（强项）

**适用**：小区、园区、写字楼、道闸、会议室。

**痛点（调研）**：

| 痛点 | 依据 |
|---|---|
| 访客登记慢、体验差、难追溯 | 访客管理厂商的共同说法：纸质登记效率低，集中来访时拥堵，记录易丢、难追溯，专人值守成本高，与门禁不通 |
| 门禁坏了没人知道，等业主投诉才发现 | 媒体报道：系统升级后门禁故障，下班高峰业主全被堵在门口；小区门禁故障引发 20 余起投诉；门禁控制器离线在后台不显眼 |
| 人脸数据合规 | 法院判决：小区强制刷脸、未经同意录入人脸，物业败诉 |

**传统都有的**：刷卡、NFC、人脸、二维码通行，访客登记。

**加了 AI 多出来的**：
- **访客管理（客户最在意的一项）**：业主或租户在业主 Agent 里一句话邀请访客，访客凭码通行，访客车同步放行，记录可查。
- **直接告诉你哪个门禁点坏了**：读头离线、开关异常自动发现，自动派单，不用人去系统里看，也不用等业主投诉。
- 远程开关。

**写法注意**：不写人员流量与性别分析；涉及人脸，一律写“经业主同意录入”。

### 5. 楼宇自控与设备能耗（特长）

**痛点（调研）**：

| 痛点 | 依据 |
|---|---|
| 系统装了但用不起来 | 格力公开材料（2026-09）：多数已运行的楼宇智控系统不能正常发挥作用，改动只能等原厂工程师，很多项目建成后被闲置，退回人工开关；早期报道也指出“重硬件轻软件、调试不到位、运维人员缺培训” |
| 系统孤岛 | 行业文章：超过 70% 的既有建筑存在多系统互不通信 |
| 告警太多、误报多、没人看 | 霍尼韦尔 Forge Cognition（2026-10）首要场景就是报警分诊，试点中非必要警报减少高达 90%，说明“告警太多”是行业公认痛点 |
| 跑冒滴漏发现晚 | 漏水、空转往往靠巡检或业主报修才发现 |

**行业动向**：霍尼韦尔、西门子、江森、施耐德都在给楼宇平台加智能体；霍尼韦尔的思路是“在既有系统上叠加，不推倒重建”，与我们一致。

**传统都有的**：空调、照明、给排水、电梯、消防等子系统监控，设备台账、巡检保养、抄表、能耗统计。

**加了 AI 多出来的**：
- **先把数据接进来**：水电表、电梯、消防、空调、能耗、照明、视频，全接进 FMClaw；不换原有设备和系统。
- **环比、同比自动分析**，异常自动发现。
- **异常直接报单**：比如监测到漏水，数据准确度够高的，直接生成工单派人。
- **能下发指令**：只要设备有接口，就能远程调控。

**和谁联动**：工单（异常报单）、收费（表计出账）、巡检。

### 1. 为什么不能只做一个总页

百度联想显示，五个系统**各有独立的采购问法**，买的人也不是同一个：

| 系统 | 用户原话（百度联想，2026-10-27） | 谁在买 |

| 业主端 / 工单 | 物业工单系统 APP、物业报修工单管理系统、物业报修系统有哪些 | 客服经理、项目经理 |
